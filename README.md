# Update channel

Nytro Audio Vocodecs development builds. Version 0.1.4 passed native ARM64 AU, processor/UI, DSP and deferred installer checks. It is an independent engine; original Vocodex sound equivalence and the 25 original Sytrus carriers are not implemented.

Install the first updater-enabled component manually. Later published versions can be installed through the plugin's top-right menu; close the loading host after staging the update.
